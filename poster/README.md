# Poster

The CS 4782 poster deliverable lives here.

- `LoRA_poster_final.pdf` is the submitted poster PDF referenced by the root
  README and final-deliverable instructions.
- `LoRA_Poster_final.html` is the editable 36" x 24" landscape source used to
  produce the PDF.

The poster's discussion matches the root README: GPT-2 Medium is frozen, LoRA
adapters are applied to Q/V, all headline runs use 5 epochs on one A100, and
MoLE is a separate routing experiment over frozen uniform `r=4` task experts.
