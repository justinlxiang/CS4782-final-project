Why LoRA?

Fine-tuning a 354M-param transformer used to mean storing a fresh 354M-param copy per task. LoRA freezes a giant weight (typically attention Q, V) W0 with dimension d×d and instead trains on two skinny matrices A ∈ ℝd×r, B ∈ ℝr×d. "Skinny" means that r ≪ d — so trainable params are significantly reduced. Why low rank works: a task lives in a small subspace of weight space, so even a tiny r (e.g., r = 4) captures most of the change. On the E2E benchmark, our replication of LoRA on GPT-2 Medium achieves:

LoRA Architecture

Freeze the giant matrix W0. Train two skinny ones, A and B, and add their product back in.

h = W0x  +  B A x
Fig. 1. The trainable path is (A, B); everything else is frozen. B initializes to 0s, so the term B A x = 0 at start of training.

Method #2 — Learn Rank Assignment through AdaLoRA-Lite

Don't pick the profile by hand — let the model learn it. Start every rank direction live, rank them by importance, drop the bottom ones until the budget hits target.

h = W0x  +  (α / rmax) · B · diag(s) · A x    (si = scalar gate per rank direction)
Fig. 3. Y-axis is total active rank units (summed over all 48 Q/V slices). Start every slice at rmax=6 (288 total), prune down to a target of 192 (= every slice at rank 4) along a cubic schedule.

Question 2
Can one served model handle multiple tasks via routed LoRAs?
6
MoLE — Mixture-of-LoRA Experts

One frozen base + three task LoRAs (one each for E2E, DART, WebNLG). A tiny router per layer (~0.07M params) picks one expert per token. One served model handles all three tasks.

Fig. 5. Same shape as original LoRA: frozen W0 on top, trainable path on the bottom — but the trainable path is now a router that picks one of three frozen LoRA experts. Top-1: per token only the chosen row's BkAkx reaches the sum.

Takeaways
  • LoRA replicates. Within 0.05 BLEU of the paper at <1% of full-FT cost.
  • Allocation > raw rank. Late-heavy r=4 beats uniform r=8 with half the params.
  • Learning rediscovers hand-design. AdaLoRA-Lite finds a late-heavy profile on its own.
